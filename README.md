# Radix Sort

## Description
This project focuses on implementing **Radix Sort**, a non-comparative sorting algorithm
that sorts integers by processing individual digits. The main goal is to understand how
digit-based sorting works and how it can achieve linear time complexity under specific
constraints.

In the context of the 42 curriculum, this project is often used to reinforce:
- Algorithmic thinking
- Time and space complexity analysis
- Low-level data manipulation (stacks/arrays depending on the subject)

## Instructions

### Compilation
```bash
make
```

This will compile the program and generate the executable.

### Execution
Run the program by passing the required arguments:
```bash
./push_swap <list_of_numbers>
```

Example:
```bash
./push_swap 3 42 1 9 0
```
